# 参照文集合の設計と限界

## 役割

参照文集合は、候補ベクトルを比較するための固定座標です。英語の自然さを代表する検証済みコーパスではなく、本ツール用に作成した300件の短い英文です。

## 構成

- 会話文
- 叙述文
- 技術的な説明文
- その他の一般文

固有名詞や専門用語を抑え、日常的な短文を中心にしています。ただし、カテゴリー数と文数をそろえるだけでは、英語全体の代表性や公平性を保証できません。

## 版と指紋

- 版: `en-300-v1`
- SHA-256: `99438d5c1522c3c66cf5378ace2cc5382f632bdb95ef111fb83758a38a3a5e31`
- 正規化規則: 英語300文をソース順のJSON配列として`JSON.stringify`し、そのUTF-8バイト列をハッシュする

参照文または順序を変更すると、指紋と版を更新します。テストはソースから指紋を再計算し、定数との一致を検査します。指紋は結果の再現条件を識別するための値であり、署名、改ざん証明、第三者による真正性保証ではありません。実行中の配列は凍結し、意図しない追加・並べ替えを防ぎます。

## 正規化

参照文は候補と同じく、小文字化、空白圧縮、前後空白の除去を行います。埋め込みは候補と同じモデル、mean pooling、L2正規化を使います。

## 重心

```text
centroid = normalize(sum(reference_i) / 300)
```

この重心は「本参照集合の中心」です。一般英語の普遍的な中心ではありません。会話文、叙述文、技術文の配分や個々の例を変えると移動します。

## 上位k参照

候補に近い参照文の上位k件を平均します。1文だけの偶然一致への依存を弱める狙いがありますが、統計的な有意性や正解率を与えるものではありません。

- k=3: 最も近い少数例への感度が高い
- k=5: 既定
- k=7: やや広い近傍を平均する

小さいkを「厳格」、大きいkを「寛容」とは定義しません。

画面ではBへ使った同じ上位k文を展開できます。集合内番号、原文、個別cosine、表示上の近さを確認できますが、近い文が存在すること自体は候補の正しさ、自然さ、出典を示しません。

## 想定する用途

- 同じ暗号文から得た複数の英語候補を読む順番の補助
- プリセット変更による順位感度の観察
- 参照集合バイアスと埋め込み類似度の学習

## 想定しない用途

- 文法的自然さの絶対評価
- 正しい平文の自動決定
- 人間の文章品質評価
- 言語判定、多言語比較、専門分野ベンチマーク

## 改善を評価する場合

参照文の追加・削除を品質改善と主張するには、正解ラベル付きの候補集合を別に用意し、Top-1、Top-k、順位相関、入力長別結果を公開する必要があります。評価用データを参照文選定へ流用すると過学習になるため分離します。

現在の評価ラボは、この分離を具体化した`eval-en-18-v1`を使います。評価平文は参照文300件と完全一致せず、参照集合の選定には使いません。ただし18ケースは小規模な学習用データであり、参照集合の品質改善や一般性能を立証するベンチマークではありません。詳細は[EVALUATION.md](EVALUATION.md)を参照してください。
