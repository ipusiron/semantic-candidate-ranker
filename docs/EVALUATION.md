# 固定評価セットと摂動比較

## 目的

評価ラボは、Semantic Candidate Rankerの順位付けが既知の小規模データでどのように振る舞うかを観察するための学習機能です。正解ラベルは集計にだけ使い、候補のスコア計算には使いません。

表示値はこの固定データ内の観測結果です。一般的な正解率、統計的な信頼度、文章品質、復号能力、最良プリセットを示すものではありません。

## データセット

| 項目 | 値 |
| --- | --- |
| 版 | `eval-en-18-v1` |
| SHA-256 | `e763264a9b2d4c5ad5104f73cfbbb0e74e40c24e8e0546ee5ebab44d28756b3a` |
| ケース数 | 18 |
| 候補数 | 108 |
| 暗号方式 | シーザー、アフィン、ヴィジュネル、ボーフォート、レールフェンス、列転置 |
| 入力長区分 | 短文、中文、長文 |
| 1ケースの候補 | 正解設定1件、誤設定5件 |

6暗号方式ごとに短文・中文・長文を1ケースずつ用意します。既知平文を各方式で暗号化し、正しい設定と5つの誤設定で復号して候補を決定的に生成します。正解候補の入力位置1～6は、それぞれ3ケースです。

ここでいう入力長はデータセット設計時の3区分です。実モデルのトークナイザーが画面へ示す短い／中程度／長い区分とは別であり、同じ境界を主張しません。

評価平文は固定参照文300件と完全一致しません。評価結果を見て候補や参照文を差し替えない方針です。この分離は明らかな自己採点を避けますが、暗号文、誤設定、文体の選び方による偏りまでは除けません。

## 版と指紋

評価セットの指紋は、候補を含む順序付きデータを決められたJSON表現にし、そのUTF-8バイト列へSHA-256を適用した値です。テストはソースから指紋を再計算します。平文、暗号設定、候補、順序を変える場合は、版と指紋を更新します。

指紋は同じ評価セットを識別する再現条件です。署名、改ざん証明、第三者による真正性保証ではありません。

## 指標

各ケースで正解候補の順位を`r`とします。

```text
Top-1 = r = 1 のケース数 / 全ケース数
Top-3 = r <= 3 のケース数 / 全ケース数
MRR = average(1 / r)
正解順位の中央値 = median(r)
```

バランス、参照重心寄り、近い参照例寄り、上位3参照、上位7参照の5プリセットを、同じ候補埋め込みへ適用します。プリセット比較で数値が最も高いものを一般的な最良設定とは判定しません。

方式別6群と入力長別3群は、バランスプリセットの結果を内訳表示したものです。ケース別表示では、正解順位、正解候補、1位候補、生成設定、比較値差を確認できます。

## 摂動比較

次の8種類を、編集可能な変更後テキストの出発点として用意します。

1. 大文字・小文字
2. 空白・改行
3. 句読点
4. 1文字の置換
5. 単語の削除
6. 一部の語順変更
7. 無関係な短文の追加
8. 256 word piecesを超える長文化

選択ケースの正解候補だけを変更し、残り5候補は固定します。変更後候補だけを再度埋め込み、変更前後の順位、比較値、A、B、上位k参照の入れ替わりを表示します。

大文字・小文字と空白は通常の正規化で吸収されるため、結果が変わらないことが期待されます。その他の変更も、順位が上がれば文章が改善した、下がれば悪化したとは解釈しません。参照集合に対する位置がどう動いたかだけを観察します。

## 再現手順

1. 評価ラボを開く
2. 版とSHA-256を記録する
3. 「内蔵18ケースを評価する」を押す
4. モデル、Transformers.js版、参照集合版・指紋が同じことを確認する
5. 5プリセットとケース別結果を記録する
6. 摂動比較ではケース、変更種類、編集後テキストを記録する

モデル関連ファイルがキャッシュされていない場合はネットワーク取得が発生します。ブラウザー、実行環境、浮動小数点処理の違いにより表示丸め前の値が微小に変わる可能性があります。

## 限界

- 18ケースは一般性能を推定するには小さい
- 6種類の古典暗号と選択した誤設定に限定される
- 評価文は本ツール用の手作りで、英語全体や実務データを代表しない
- 候補の難しさや相互の近さを均等にした統計標本ではない
- 同じ正解文でも、競合候補を変えれば順位は変わる
- Top-1、Top-3、MRRに信頼区間や有意差検定を付けていない
- 256 word pieces以降はモデル入力に使われない
- この結果だけで参照集合の追加・削除やプリセットの変更を正当化しない
