# スコアリングアルゴリズム詳解

## 目的

候補を、固定した英語参照文集合との意味類似度で並べます。文法的な自然さ、文章品質、復号の正しさを直接測るアルゴリズムではありません。

## 前提

- 候補と参照文は384次元のL2正規化済みベクトルへ変換する
- 候補は256 word piecesまでを使用する
- メタデータは埋め込みから除外する
- 参照文は固定300文である

## 1. 参照集合の重心との近さ

参照ベクトルの平均をL2正規化して重心を作り、候補とのコサイン類似度を求めます。

```text
centroid = normalize(sum(reference_i) / N)
raw_A = cosine(candidate, centroid)
A = clamp((raw_A + 1) / 2, 0, 1)
```

Aは参照集合全体の中心への近さです。「一般的な英語の重心」や「自然さ」とは呼びません。参照文の選び方を変えると値が変わります。

## 2. 上位k参照との近さ

候補と全参照文の類似度を降順に並べ、上位k件の平均を取ります。

```text
raw_B = average(sort_desc(cosine(candidate, reference_i))[0:k])
B = clamp((raw_B + 1) / 2, 0, 1)
```

Bは候補に近い参照例群への近さです。kが小さいほど必ず厳しくなるわけではありません。

計算時は各値を`{referenceIndex, cosineSimilarity}`として保持し、cosine降順、同値の場合は`referenceIndex`昇順で並べます。画面の展開欄は、Bの平均へ使った同じ上位k件について、参照集合内番号、原文、元のcosine、`(cosine + 1) / 2`を表示します。この内訳は計算の説明であり、正しさや自然さの証拠ではありません。

## 3. 合成値

```text
comparison_score = clamp(wA * A + wB * B, 0, 1)
```

| プリセット | wA | wB | k |
| --- | ---: | ---: | ---: |
| balanced | 0.5 | 0.5 | 5 |
| centroid | 0.7 | 0.3 | 5 |
| neighbors | 0.3 | 0.7 | 5 |
| top3 | 0.5 | 0.5 | 3 |
| top7 | 0.5 | 0.5 | 7 |

合成値で降順に並べます。同値は入力順を保ちます。正解付き評価データによる校正を行っていないため、固定しきい値や「優秀／不良」の判定は設けません。

## 4. 入力長

実モデルのトークナイザーで、特殊トークンを含むword piecesを数えます。256を超えると、実際の埋め込みは先頭256だけを使います。画面には使用数と元の数を出します。

短い／中程度／長いという区分は入力サイズの記述であり、統計的信頼度ではありません。

## 5. 計算量

- 参照文埋め込み: `O(N × model)`。セッション内でキャッシュする
- 候補埋め込み: `O(M × model)`
- 類似度: `O(M × N × d)`
- 参照類似度のソート: `O(M × N log N)`

`N=300`、`M≤200`、`d=384`です。

## 6. 解釈上の限界

- 値は固定参照集合に依存する
- 候補間の小差に有意性検定や誤差幅はない
- 正しい復号が参照集合と遠い表現なら順位が下がり得る
- 無意味な文字列が偶然参照ベクトルに近づく場合がある
- 超過部分に判別情報があっても、256 word pieces以降は使われない

## 7. 固定評価セットの集計

評価ラボでは、各ケースの正解候補に付けたラベルを順位計算後に照合します。正解ラベルをスコア計算へ入力することはありません。

```text
Top-1 = 正解順位が1のケース数 / 全ケース数
Top-3 = 正解順位が3以下のケース数 / 全ケース数
MRR = average(1 / 正解順位)
median_rank = 正解順位の中央値
```

18ケースを同じ候補埋め込みで5プリセットへ通し、プリセットごとに再順位付けします。暗号方式別6群と入力長別3群は、バランスプリセットの同じケース結果を再集計します。入力長群は評価セット作成時の区分であり、実トークナイザーによる短い／中程度／長い表示とは別です。

これらは`eval-en-18-v1`内の観測値です。一般的な正解率、信頼区間、最良プリセット、将来入力の性能を示しません。

## 8. 摂動前後の比較

選択ケースの正解候補だけを変更し、残り5候補の埋め込みは固定します。変更後の候補を同じモデル、参照集合、プリセットで再計算し、次を差分表示します。

```text
rank_delta = rank_after - rank_before
score_delta = score_after - score_before
A_delta = A_after - A_before
B_delta = B_after - B_before
changed_neighbors = 対称差となった上位k参照の件数
```

順位差の正負は移動方向を表すだけで、文章品質の改善・悪化を意味しません。大文字・小文字と空白は正規化で同じ入力になるため、値が変わらないことも想定した観察対象です。
